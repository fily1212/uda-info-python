## Concetti Chiave OOP

### 1. **Classe e Oggetto**
Una **classe** è un modello (blueprint), un **oggetto** è un'istanza concreta.

```python
class Cane:
    def __init__(self, nome):
        self.nome = nome

fido = Cane("Fido")  # fido è un oggetto/istanza
```

### 2. **Attributi**
- **Attributi di istanza**: specifici per ogni oggetto
- **Attributi di classe**: condivisi da tutte le istanze

```python
class Auto:
    ruote = 4  # attributo di classe

    def __init__(self, marca):
        self.marca = marca  # attributo di istanza
```

### 3. **Metodi**
- **Metodi di istanza**: operano su un oggetto specifico (self)
- **Metodi di classe**: operano sulla classe (@classmethod)
- **Metodi statici**: funzioni indipendenti (@staticmethod)

### 4. **Ereditarietà**
Una classe "figlia" eredita attributi e metodi dalla classe "genitore".

```python
class Animale:
    def respira(self):
        print("Sto respirando")

class Cane(Animale):
    def abbaia(self):
        print("Bau!")

fido = Cane()
fido.respira()  # Ereditato da Animale
fido.abbaia()
```

### 5. **Polimorfismo**
Oggetti di classi diverse rispondono allo stesso metodo in modi diversi.

```python
class Gatto:
    def verso(self):
        return "Miao"

class Cane:
    def verso(self):
        return "Bau"

# Stesso metodo, comportamento diverso
animali = [Gatto(), Cane()]
for animale in animali:
    print(animale.verso())
```

### 6. **Incapsulamento**
Nascondere i dettagli interni di una classe (attributi privati con `_` o `__`).

```python
class ContoCorrente:
    def __init__(self, saldo):
        self.__saldo = saldo  # attributo privato

    def deposita(self, importo):
        self.__saldo += importo
```

### 7. **Composizione**
Una classe contiene oggetti di altre classi ("has-a" relationship).

```python
class Motore:
    pass

class Auto:
    def __init__(self):
        self.motore = Motore()  # Auto "ha un" Motore
```

## FAQ

### Quando devo usare le classi?
Usa le classi quando hai dati e comportamenti strettamente correlati che rappresentano un'entità del mondo reale o un concetto astratto.

### Differenza tra funzione e metodo?
Un **metodo** è una funzione definita all'interno di una classe e opera sugli oggetti di quella classe.

### Quando usare ereditarietà vs composizione?
- **Ereditarietà** ("is-a"): Cane **è un** Animale
- **Composizione** ("has-a"): Auto **ha un** Motore

Generalmente, **preferisci la composizione** per maggiore flessibilità.

### self è obbligatorio?
Sì, `self` è il primo parametro di tutti i metodi di istanza. Rappresenta l'oggetto corrente.

### Posso creare attributi privati?
Usa `_` per convenzione (privato) o `__` per name mangling (più privato).

```python
class Esempio:
    def __init__(self):
        self._privato = 1      # convenzione
        self.__piu_privato = 2  # name mangling
```
