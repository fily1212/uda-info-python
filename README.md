# UDA Informatica - Python

## Autore
**Prof. Zhongli Filippo Hu**
ITIS Grassi

## Descrizione
Questo repository contiene materiale didattico ed esercizi di programmazione Python pensati per studenti di una classe seconda ITIS. Gli esercizi coprono diverse discipline (fisica, matematica, italiano, telecomunicazioni, videogiochi) e sono organizzati per argomenti e difficoltà crescente, seguendo il programma ministeriale di informatica.

## Obiettivi
- Apprendere i fondamenti della programmazione Python
- Sviluppare capacità di problem solving
- Applicare la programmazione a contesti interdisciplinari
- Acquisire competenze pratiche nella scrittura di codice

## Struttura del Repository

### 📁 [Esercizi di Informatica - OOP](./esercizi-info/)
**Programmazione Orientata agli Oggetti** (20 esercizi): uso classi esistenti (matplotlib, numpy, pandas, pathlib), creazione classi proprie, ereditarietà, polimorfismo, metodi speciali, composizione, classi astratte, progetto finale gestionale.

### 📁 [Esercizi di Fisica](./esercizi-fisica/)
Simulazioni e visualizzazioni di fenomeni fisici (8 esercizi): cinematica, pendolo, circuiti, moto planetario, onde, ecc.

### 📁 [Esercizi di Matematica](./esercizi-matematica/)
Applicazioni Python per concetti matematici (8 esercizi): funzioni, derivate, Monte Carlo, probabilità, statistica, ecc.

### 📁 [Esercizi di Italiano](./esercizi-python-italiano/)
Python per la letteratura italiana (10 esercizi): analisi testi, haiku, rime, quiz letterario, racconti, bot Telegram, blog Flask, ecc.

### 📁 [Esercizi di Telecomunicazioni](./esercizi-tlc/)
Teoria dei segnali e telecomunicazioni (10 esercizi): modulazione, dB/SNR, codifica Manchester, FFT, protocolli, crittografia RSA, ecc.

### 📁 [Esercizi di Telecomunicazioni - Programma Ministeriale](./esercizi-tlc-new/)
**TLC per Seconda ITIS** (10 esercizi Python/JavaScript): segnali, circuiti elettrici, mezzi trasmissivi, onde EM, logica digitale, porte logiche, circuiti combinatori, simulatore web, quiz sicurezza.

### 📁 [Esercizi di Videogiochi](./esercizi-videogiochi/)
Narrativa interattiva e game development (7 esercizi): avventure testuali, dialoghi, inventario, combattimento, Pygame, editor storie, ecc.

### 📁 [UDA Avventura Testuale](./uda-avventura-testuale/)
Progetto completo: creare avventure testuali con parser di linguaggio naturale, combinando scrittura creativa e programmazione.

## Prerequisiti
- Python 3.8 o superiore
- Conoscenze base di programmazione (variabili, cicli, funzioni)
- Editor di testo o IDE (consigliato: VS Code, PyCharm)

## Come Utilizzare
1. Clona o scarica questo repository
2. Naviga nella cartella tematica di interesse
3. Leggi il README.md della cartella per vedere gli esercizi disponibili
4. Entra nella cartella dell'esercizio specifico
5. Segui le istruzioni nella cartella `consegna/`
6. Confronta il tuo lavoro con la `soluzione/` (solo dopo aver provato!)
