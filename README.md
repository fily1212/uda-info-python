# UDA Informatica - Python

## Autore
**Prof. Zhongli Filippo Hu**
ITIS Grassi

## Descrizione
Questo repository contiene materiale didattico ed esercizi di programmazione Python pensati per studenti di una classe seconda ITIS. Gli esercizi sono organizzati per argomenti e difficoltà crescente, seguendo il programma ministeriale di informatica.

## Obiettivi
- Apprendere i fondamenti della programmazione Python
- Sviluppare capacità di problem solving
- Acquisire competenze pratiche nella scrittura di codice

## Struttura
Il repository è organizzato in cartelle tematiche, ciascuna contenente:
- Esercizi pratici in Python
- File README.md con spiegazioni e istruzioni
- Soluzioni commentate (dove disponibili)
