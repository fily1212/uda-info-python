## Concetti Chiave TLC

### 1. **Segnale**
Un segnale è una grandezza fisica che varia nel tempo e trasporta informazione.

**Parametri principali:**
- **Ampiezza (A)**: valore massimo del segnale
- **Periodo (T)**: tempo per completare un ciclo [secondi]
- **Frequenza (f)**: numero di cicli al secondo [Hz], f = 1/T

```python
# Segnale sinusoidale
import numpy as np
y = A * np.sin(2 * np.pi * f * t)
```

### 2. **Legge di Ohm**
Relazione fondamentale tra tensione, corrente e resistenza.

```
V = R × I

V: Tensione [Volt]
I: Corrente [Ampere]
R: Resistenza [Ohm]
```

**Potenza elettrica:**
```
P = V × I = R × I² = V²/R [Watt]
```

### 3. **Resistenze in Serie e Parallelo**

**Serie:**
```
Req = R1 + R2 + R3 + ...
```

**Parallelo:**
```
1/Req = 1/R1 + 1/R2 + 1/R3 + ...
```

### 4. **Mezzi Trasmissivi**

| Mezzo | Velocità | Distanza | Costo | Uso |
|-------|----------|----------|-------|-----|
| **Rame** | Media | Breve | Basso | LAN |
| **Coassiale** | Media | Media | Medio | TV |
| **Fibra ottica** | Alta | Lunga | Alto | Backbone |
| **Aria (wireless)** | Alta | Variabile | Basso | WiFi, 5G |

### 5. **Onde Elettromagnetiche**

Relazione fondamentale:
```
c = λ × f

c: velocità della luce (3×10⁸ m/s)
λ: lunghezza d'onda [metri]
f: frequenza [Hz]
```

### 6. **Porte Logiche**

| Porta | Simbolo | Funzione | Output |
|-------|---------|----------|--------|
| **AND** | · | Moltiplicazione | 1 se A=1 E B=1 |
| **OR** | + | Somma | 1 se A=1 O B=1 |
| **NOT** | ¬ | Negazione | Inverte input |
