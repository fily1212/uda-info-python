# UDA Fisica e Informatica

## Python per la Fisica

Simulazioni e visualizzazioni di fenomeni fisici usando Python.

## Esercizi

### 🚗 Es1: Simulatore di Moto (BASE)
Cinematica: moto rettilineo, parabolico, grafiitempo, velocità, accelerazione.

### ⚖️ Es2: Pendolo Semplice Animato (INTERMEDIO)
Animazione pendolo, studio periodo, energia, moto armonico.

### ⚡ Es3: Circuiti e Leggi di Ohm (INTERMEDIO)
Calcolatore circuiti, resistenze, legge di Ohm, potenza.

### 🪐 Es4: Moto Planetario (AVANZATO)
Simulazione gravitazionale, orbite, leggi di Keplero, n-body.

### 🌊 Es5: Onde e Interferenza (AVANZATO)
Simulazione onde, interferenza, diffrazione, fenomeni ondulatori.

---

**Prerequisiti:** Python 3.8+, fisica del liceo

**Durata totale:** 20-25 ore
