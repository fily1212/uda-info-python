# UDA Telecomunicazioni e Informatica

## Python per le Telecomunicazioni

Esercizi interdisciplinari che combinano programmazione Python e concetti di telecomunicazioni e teoria dei segnali.

## Esercizi

### 📡 Es1: Modulazione di Segnali (BASE)
Simulazione AM, FM, PM - visualizzazione forme d'onda, spettro.

### 📊 Es2: Calcolatore dB e SNR (FACILE)
Conversioni dB/dBm/watt, calcolo SNR, budget di collegamento.

### 💾 Es3: Codifica Manchester e NRZ (INTERMEDIO)
Codifiche di linea, clock recovery, eye diagram.

### 🌈 Es4: Analizzatore di Spettro (INTERMEDIO)
FFT, analisi frequenze, waterfall, spettrogramma.

### 🔄 Es5: Simulatore Protocolli (AVANZATO)
Stop-and-Wait, Sliding Window, ARQ, Go-Back-N.

### 🎛️ Es6: Filtri Digitali (INTERMEDIO-AVANZATO)
FIR, IIR, passa-basso, passa-alto, passa-banda.

### 📏 Es7: Campionamento e Nyquist (BASE-INTERMEDIO)
Teorema del campionamento, aliasing, ricostruzione.

### 🔐 Es8: Crittografia RSA (AVANZATO)
Chiavi pubbliche/private, cifratura, firma digitale.

### 📶 Es9: Analizzatore WiFi/Bluetooth (INTERMEDIO)
Scansione reti, analisi canali, RSSI, interferenze.

### 🔌 Es10: Comunicazione Seriale (BASE)
UART, RS232, protocolli seriali, invio/ricezione dati.

---

**Prerequisiti:** Python 3.8+, nozioni base di telecomunicazioni

**Durata totale:** 30-35 ore
