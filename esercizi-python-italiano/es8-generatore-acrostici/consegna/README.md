# Esercizio 8: Generatore di Acrostici

## Livello: INTERMEDIO

## Obiettivi
- **Informatica**: Algoritmi, dizionari, file, API opzionale
- **Italiano**: Poesia acrostica, creatività lessicale

## Descrizione
Crea un programma che genera poesie acrostiche: ogni verso inizia con una lettera della parola chiave.

## Esempio
Parola: AMORE

```
Anime che si incontrano
Mondi che si fondono
Occhi che parlano
Respiri sincronizzati
Eternità in un istante
```

## Requisiti
1. Input: parola chiave
2. Generare versi che iniziano con ogni lettera
3. Usare database di versi o API sinonimi
4. Salvare poesie generate

## Installazione
```bash
pip install requests  # per API sinonimi opzionale
```

## Consegna
Salva come `genera_acrostico.py` e genera almeno 5 acrostici diversi.
