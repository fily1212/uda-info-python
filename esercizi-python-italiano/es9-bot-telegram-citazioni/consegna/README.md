# Esercizio 9: Bot Telegram Citazioni Letterarie

## Livello: INTERMEDIO-AVANZATO

## Obiettivi
- **Informatica**: Bot Telegram, API, async programming
- **Italiano**: Citazioni letterarie, autori italiani

## Descrizione
Crea un bot Telegram che invia citazioni letterarie casuali o per autore.

## Comandi
- `/start` - Messaggio benvenuto
- `/citazione` - Citazione casuale
- `/autore <nome>` - Citazioni di un autore specifico
- `/random` - Citazione casuale
- `/help` - Aiuto

## Installazione
```bash
pip install python-telegram-bot
```

## Setup
1. Crea bot con @BotFather su Telegram
2. Ottieni token
3. Crea file .env con TOKEN

## Consegna
Database di almeno 30 citazioni di 5+ autori italiani.
