# Esercizio 11: Biblioteca Digitale con Flask

## Livello: MOLTO AVANZATO

## Obiettivi
- **Informatica**: Flask, file upload, database relazionale, search
- **Italiano**: Catalogazione opere, metadata letterari

## Descrizione
Sistema completo di gestione biblioteca digitale con upload libri, ricerca, prestiti virtuali.

## Funzionalità
- Upload file PDF/EPUB
- Database libri con metadata (autore, anno, genere, ISBN)
- Ricerca full-text
- Sistema prestiti virtuali con scadenze
- Statistiche lettura
- Export catalogo

## Installazione
```bash
pip install Flask Flask-SQLAlchemy Flask-Uploads PyPDF2
```

## Consegna
Database con almeno 10 libri della letteratura italiana con metadata completi.
