## Descrizione del Progetto

Questa **Unità Didattica di Apprendimento (UDA)** interdisciplinare combina lo studio della programmazione Python con la letteratura italiana. Gli studenti impareranno a programmare creando applicazioni che analizzano, generano e gestiscono contenuti letterari.

### Obiettivi Formativi

#### Competenze Informatiche
- Manipolazione di stringhe e strutture dati
- Utilizzo di funzioni e modularizzazione del codice
- Programmazione orientata agli oggetti (base)
- Sviluppo web con Flask
- File I/O e gestione dati
- Randomizzazione e algoritmi

#### Competenze Italiano
- Analisi testuale e metrica
- Comprensione della struttura narrativa
- Conoscenza della letteratura italiana
- Creatività letteraria
- Elementi della poesia (haiku, rime)

## Struttura degli Esercizi

Il percorso didattico è strutturato in **10 esercizi progressivi** che aumentano gradualmente in complessità:

### 📊 Esercizio 1: Analizzatore di Testo
**Livello:** BASE
**Durata stimata:** 2-3 ore
**Concetti Python:** stringhe, funzioni, cicli, condizioni
**Concetti Italiano:** analisi testuale, elementi grammaticali

Crea un programma che analizza un testo e fornisce statistiche dettagliate (numero di parole, frasi, vocali/consonanti, parola più lunga, ecc.).

📁 [Vai all'esercizio 1](./es1-analizzatore-testo/)

---

### 🎋 Esercizio 2: Generatore di Haiku
**Livello:** INTERMEDIO
**Durata stimata:** 3-4 ore
**Concetti Python:** liste, dizionari, random, strutture dati
**Concetti Italiano:** poesia giapponese, sillabe, metrica

Sviluppa un programma che genera automaticamente haiku rispettando la metrica tradizionale 5-7-5 sillabe.

📁 [Vai all'esercizio 2](./es2-generatore-haiku/)

---

### 🎵 Esercizio 3: Generatore di Rime
**Livello:** INTERMEDIO
**Durata stimata:** 3-4 ore
**Concetti Python:** dizionari, pattern matching, file, algoritmi
**Concetti Italiano:** rime, terminazioni delle parole, poesia

Costruisci un programma che trova parole in rima dato un vocabolario e permette di espanderlo.

📁 [Vai all'esercizio 3](./es3-generatore-rime/)

---

### 🌐 Esercizio 4: Quiz Letterario Flask
**Livello:** AVANZATO
**Durata stimata:** 5-6 ore
**Concetti Python:** web development, Flask, HTML, routing, sessioni
**Concetti Italiano:** letteratura italiana, autori, opere, citazioni

Crea un'applicazione web interattiva che propone un quiz sulla letteratura italiana con sistema di punteggio e feedback.

📁 [Vai all'esercizio 4](./es4-quiz-letterario-flask/)

---

### 📖 Esercizio 5: Generatore di Racconti
**Livello:** AVANZATO
**Durata stimata:** 5-7 ore
**Concetti Python:** strutture dati complesse, randomizzazione, logica, file I/O
**Concetti Italiano:** struttura narrativa, personaggi, trama, elementi del racconto

Sviluppa un programma che genera automaticamente racconti brevi combinando elementi narrativi casuali mantenendo coerenza.

📁 [Vai all'esercizio 5](./es5-generatore-racconti/)

---

### 🤖 Esercizio 6: Generatore di Racconti con AI
**Livello:** AVANZATO
**Durata stimata:** 5-7 ore
**Concetti Python:** API calls, integrazione servizi esterni, gestione chiavi, async/await
**Concetti Italiano:** generazione creativa assistita, storytelling, prompt engineering

Potenzia il generatore di racconti integrando un modello di linguaggio AI per creare storie più elaborate e coerenti.

📁 [Vai all'esercizio 6](./es6-generatore-racconti-ai/)

---

### 📈 Esercizio 7: Analizzatore di Frequenze
**Livello:** INTERMEDIO
**Durata stimata:** 3-4 ore
**Concetti Python:** analisi statistica, grafici, elaborazione testi, dizionari
**Concetti Italiano:** analisi lessicale, frequenza parole, vocabolario

Crea un programma che analizza la frequenza di parole e caratteri in testi letterari, con visualizzazione grafica dei risultati.

📁 [Vai all'esercizio 7](./es7-analizzatore-frequenze/)

---

### 🔤 Esercizio 8: Generatore di Acrostici
**Livello:** INTERMEDIO
**Durata stimata:** 3-4 ore
**Concetti Python:** algoritmi di ricerca, dizionari, pattern matching, creatività computazionale
**Concetti Italiano:** acrostici, poesia, creatività letteraria

Sviluppa un programma che genera acrostici: poesie dove le prime lettere di ogni verso formano una parola o frase.

📁 [Vai all'esercizio 8](./es8-generatore-acrostici/)

---

### 💬 Esercizio 9: Bot Telegram Citazioni Letterarie
**Livello:** AVANZATO
**Durata stimata:** 5-6 ore
**Concetti Python:** bot development, Telegram API, gestione comandi, database
**Concetti Italiano:** citazioni letterarie, autori italiani, opere classiche

Crea un bot Telegram che invia citazioni letterarie casuali, cerca citazioni per autore/opera, e permette agli utenti di salvare le loro preferite.

📁 [Vai all'esercizio 9](./es9-bot-telegram-citazioni/)

---

### 📝 Esercizio 10: Blog Letterario con Flask
**Livello:** AVANZATO
**Durata stimata:** 6-8 ore
**Concetti Python:** Flask avanzato, database, autenticazione, CRUD, templating
**Concetti Italiano:** recensioni letterarie, blog, critica letteraria

Costruisci un'applicazione web completa per un blog letterario con articoli, commenti, categorie, ricerca e gestione utenti.

📁 [Vai all'esercizio 10](./es10-blog-letterario-flask/)

## Come Utilizzare Questo Repository

### Prerequisiti

- Python 3.8 o superiore installato
- Editor di testo o IDE (consigliato: VS Code, PyCharm)
- Conoscenze base di Python (variabili, cicli, funzioni)

### Installazione

1. **Clona o scarica** questo repository
2. **Naviga** nella cartella dell'esercizio che vuoi svolgere
3. **Leggi** il file `README.md` nella cartella `consegna/`
4. **Inizia** a programmare!

### Struttura delle Cartelle

Ogni esercizio è organizzato così:

```
esN-nome-esercizio/
├── consegna/
│   ├── README.md          # Istruzioni dettagliate
│   ├── file_partenza.py   # File con struttura base (da completare)
│   └── requirements.txt   # Dipendenze (se necessarie)
└── soluzione/
    ├── file_soluzione.py  # Soluzione completa
    └── altri_file...      # File aggiuntivi
```

### Modalità di Lavoro Consigliata

1. **Leggi** attentamente il README della consegna
2. **Pianifica** la struttura del programma prima di scrivere codice
3. **Scrivi** il codice partendo dal file di partenza
4. **Testa** frequentemente il tuo programma
5. **Consulta** la soluzione solo dopo aver provato autonomamente
6. **Migliora** il tuo codice confrontandolo con la soluzione

## Percorso Didattico Suggerito

### Per gli Studenti

**Settimana 1-2:** Esercizio 1 (Analizzatore di Testo)
- Familiarizzazione con stringhe e funzioni
- Test con testi letterari italiani

**Settimana 3-4:** Esercizio 2 (Generatore di Haiku)
- Introduzione a liste e random
- Studio della poesia giapponese

**Settimana 5-6:** Esercizio 3 (Generatore di Rime)
- Approfondimento dizionari e pattern matching
- Analisi delle rime nella poesia italiana

**Settimana 7-9:** Esercizio 4 (Quiz Letterario Flask)
- Introduzione allo sviluppo web
- Ripasso letteratura italiana

**Settimana 10-11:** Esercizio 5 (Generatore di Racconti)
- Creatività narrativa e algoritmica
- Strutture dati complesse

**Settimana 12-13:** Esercizio 6 (Generatore Racconti AI)
- Integrazione API esterne
- Prompt engineering

**Settimana 14-15:** Esercizio 7 (Analizzatore Frequenze)
- Analisi statistica testuale
- Visualizzazione dati

**Settimana 16-17:** Esercizio 8 (Generatore Acrostici)
- Algoritmi creativi
- Pattern matching avanzato

**Settimana 18-19:** Esercizio 9 (Bot Telegram)
- Bot development
- API Telegram

**Settimana 20-22:** Esercizio 10 (Blog Flask)
- Progetto finale complesso
- Web development avanzato

### Per i Docenti

Questa UDA può essere utilizzata in vari modi:

- **Progetto di classe:** Tutti gli studenti seguono lo stesso percorso
- **Lavoro a gruppi:** Gruppi diversi lavorano su esercizi diversi
- **Apprendimento personalizzato:** Ogni studente procede al proprio ritmo
- **Flipped classroom:** Gli studenti studiano a casa e portano domande in classe

#### Valutazione Suggerita

| Criterio | Peso |
|----------|------|
| Funzionamento corretto del codice | 30% |
| Qualità del codice (leggibilità, organizzazione) | 25% |
| Creatività e personalizzazione | 20% |
| Completezza delle funzionalità | 15% |
| Documentazione e commenti | 10% |

## Estensioni e Progetti Avanzati

Una volta completati tutti gli esercizi, gli studenti possono:

- **Combinare** più esercizi (es: quiz + generatore di haiku)

- **Aggiungere** un database per memorizzare dati permanentemente
- **Implementare** un sistema di login e utenti multipli
- **Pubblicare** l'applicazione online (Heroku, PythonAnywhere)
- **Creare** un'API REST per i servizi sviluppati

## FAQ

### Quanto tempo serve per completare tutti gli esercizi?
Circa 40-50 ore totali, distribuite su 20-22 settimane.

### Posso modificare gli esercizi?
Assolutamente sì! Incoraggiamo la personalizzazione e la creatività.

### Cosa faccio se rimango bloccato?
1. Rileggi le istruzioni
2. Cerca su internet (Google, Stack Overflow)
3. Chiedi al docente
4. Consulta la soluzione per avere spunti (non copiare!)

### Gli esercizi devono essere svolti in ordine?
È consigliato seguire l'ordine progressivo, ma gli studenti più esperti possono iniziare da esercizi più avanzati.
