# Esercizio 1: Visualizzatore di Funzioni Matematiche

## Livello: BASE-INTERMEDIO

## Obiettivi
- **Matematica**: Funzioni, grafici, dominio/codominio, analisi
- **Informatica**: Matplotlib, NumPy, input parsing

## Descrizione
Programma che grafica funzioni matematiche e ne studia le proprietà.

## Funzionalità
1. Input funzione (es: x**2, sin(x), log(x))
2. Grafico su intervallo
3. Trova zeri, massimi, minimi
4. Calcola area sotto curva (integrale numerico)
5. Multiple funzioni su stesso grafico

## Installazione
```bash
pip install matplotlib numpy scipy
```

## Esempio Output
```
f(x) = x**2 - 4
Intervallo: [-5, 5]
Zeri: x = -2.0, x = 2.0
Minimo: (-0.0, -4.0)
Area: 33.33
```

## Consegna
Graficare almeno 5 funzioni diverse con analisi completa.
