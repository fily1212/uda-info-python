# UDA Matematica e Informatica

## Python per la Matematica

Esercizi interdisciplinari che combinano programmazione Python e concetti matematici.

## Esercizi

### 📊 Es1: Visualizzatore di Funzioni (BASE-INTERMEDIO)
Graficare funzioni matematiche con matplotlib, studio di funzione interattivo.

### 📐 Es2: Calcolatore di Derivate e Limiti (INTERMEDIO-AVANZATO)
Calcolo simbolico con SymPy: derivate, integrali, limiti, serie di Taylor.

### 🎲 Es3: Simulatore Monte Carlo (AVANZATO)
Simulazioni probabilistiche: calcolo di π, problemi di probabilità, statistica.

---

**Prerequisiti:** Python 3.8+, conoscenze di matematica del liceo

**Durata totale:** 15-20 ore
