# Esercizio 2: Calcolatore di Derivate e Limiti

## Livello: INTERMEDIO-AVANZATO

## Obiettivi
- **Matematica**: Derivate, integrali, limiti, serie di Taylor
- **Informatica**: SymPy, calcolo simbolico, LaTeX output

## Descrizione
Calcolatore simbolico completo usando SymPy.

## Funzionalità
1. Derivate (prima, seconda, n-esima)
2. Integrali definiti e indefiniti
3. Limiti
4. Serie di Taylor/Maclaurin
5. Semplificazione espressioni
6. Output in LaTeX

## Installazione
```bash
pip install sympy
```

## Esempio
```
f(x) = x**3 - 6*x**2 + 9*x + 1
f'(x) = 3*x**2 - 12*x + 9
f''(x) = 6*x - 12
Punti critici: x = 1, x = 3
∫f(x)dx = x**4/4 - 2*x**3 + 9*x**2/2 + x
```
