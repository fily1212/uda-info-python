# UDA Videogiochi - Narrativa Interattiva

## Creare Storie Videoludiche con Python

Unità Didattica di Apprendimento che combina **scrittura creativa**, **narrativa interattiva** e **programmazione** per creare videogiochi testuali e grafici.

---

## Obiettivi

### Competenze Italiano
- Scrittura creativa e narrativa
- Costruzione trame e personaggi
- Dialoghi e descrizioni
- Scelte narrative e conseguenze
- Worldbuilding

### Competenze Informatica
- Programmazione orientata agli oggetti
- Strutture dati (dizionari, classi)
- Logica condizionale complessa
- Event handling
- Game loop
- Grafica con pygame (opzionale)

---

## Esercizi

### 🎮 Es1: Motore Base Avventura Testuale (FACILE)
Crea il motore fondamentale per storie interattive: stanze, movimenti, descrizioni.

**Output:** Sistema di navigazione tra stanze con comandi testuali.

---

### 📖 Es2: Storia a Scelte Multiple (BASE)
Scrivi una storia interattiva dove ogni scelta influenza la trama.

**Output:** Racconto interattivo con almeno 3 finali diversi.

**Esempio:**
```
Ti svegli in una foresta oscura...
1. Segui il sentiero a destra
2. Segui il sentiero a sinistra
3. Rimani fermo e grida aiuto
```

---

### 💬 Es3: Sistema di Dialoghi e Personaggi (INTERMEDIO)
Implementa un sistema di conversazioni con NPC (personaggi non giocabili).

**Features:**
- Database personaggi con personalità
- Albero di dialoghi
- Relazioni con NPC che cambiano
- Informazioni sbloccabili

---

### 🎒 Es4: Inventario e Sistema di Oggetti (INTERMEDIO)
Crea un sistema di inventario con oggetti raccoglibili e utilizzabili.

**Features:**
- Raccolta oggetti
- Combinazione oggetti
- Oggetti chiave per proseguire
- Peso e limiti inventario

---

### ⚔️ Es5: Sistema di Combattimento a Turni (INTERMEDIO-AVANZATO)
Implementa combattimenti RPG-style con statistiche e abilità.

**Features:**
- HP, MP, Attacco, Difesa
- Abilità speciali
- Nemici con AI base
- Sistema esperienza/livelli

---

### 🎨 Es6: Avventura Grafica con Pygame (AVANZATO)
Trasforma la tua avventura testuale in un gioco grafico 2D.

**Features:**
- Sprite e animazioni
- Mappa esplorabili
- Click per interagire
- Interfaccia grafica

---

### 🛠️ Es7: Editor di Storie Interattive (AVANZATO)
Crea un tool per scrivere storie interattive senza programmare.

**Features:**
- GUI per creare storie
- Export in JSON
- Import e gioca storie
- Condivisione storie

---

## Progetto Finale

Alla fine dell'UDA, gli studenti dovranno creare un **videogioco completo** che include:

1. **Storia** (Italiano)
   - Trama articolata con inizio, sviluppo, climax, conclusione
   - Almeno 5 personaggi caratterizzati
   - 3+ finali alternativi
   - Ambientazione dettagliata

2. **Implementazione** (Informatica)
   - Almeno 10 stanze/location
   - Sistema dialoghi funzionante
   - 5+ oggetti interattivi
   - 2+ enigmi da risolvere

3. **Presentazione**
   - Document design (GDD - Game Design Document)
   - Diagramma di flusso della storia
   - Demo giocabile

Gli studenti possono scegliere tra:

- 🕵️ **Giallo/Investigativo**: Risolvi un mistero

- 😱 **Horror**: Sopravvivi al terrore
- 💕 **Romantico**: Storie d'amore interattive
- 🎓 **Educativo**: Impara giocando
- 🏛️ **Storico**: Vivi eventi del passato

## Strumenti Consigliati

### Python Base
- `input()` e `print()` per interazione
- Dizionari per dati di gioco
- Classi per personaggi/oggetti

### Librerie Opzionali
```bash
pip install pygame  # Per grafica
pip install colorama  # Per testo colorato
pip install pyfiglet  # Per ASCII art
```
